# Часть 1. Что нужно сделать тебе

Через API это недоступно: зон в `dns-master` нет (записи обслуживает облачная
платформа Руцентра, её API не отдаёт), а прав на изменение услуг у токена нет.
Всё ниже делается в веб-кабинете `nic.ru`.

Пути в меню указаны примерно — кабинет периодически перерисовывают, ориентируйся
на названия разделов.

## 1. Идентификация через Госуслуги — срок 1 сентября

**Зачем:** без неё домен нельзя будет продлить, сменить NS или передать.
По окончании оплаченного периода он уходит в свободную продажу.

**Где:** Аккаунт → Договор → кнопка «Пройти идентификацию» справа от данных
администратора. Либо по ссылке, которую Руцентр сам присылает с
`noreply@nic.ru` на административный адрес домена (рассылка по понедельникам).

**Что нужно:** подтверждённая учётная запись на Госуслугах. Делается один раз
на договор, не на каждый домен.

Твои домены оплачены до июля 2027, так что продление горит не сразу — но
управление зоной может упереться раньше. Лучше закрыть сейчас.

## 2. Автопродление

Сейчас включено **только** у домена `komandor-nsk.ru`. У остальных четырёх
услуг — выключено.

**Где:** Услуги → выбрать услугу → переключатель «Автопродление».

Что я бы включил:

| Услуга | Включать? | Почему |
|---|---|---|
| KHROM-IN.RU (домен) | да, если домен нужен | иначе потеря домена в июле 2027 |
| KOM7674742 (почта, платная) | да | рабочая почта на komandor-nsk.ru, отключится молча |
| KHR7805387 (почта, бесплатная) | нет | тариф всё равно не продлевается бесплатно |
| KHROM-IN.RU (SSL) | по ситуации | пока не на чем использовать |

Проверь, что к договору привязан способ оплаты — иначе автопродление не
сработает и создаст ложное чувство безопасности.

## 3. DMARC для komandor-nsk.ru

**Зачем:** SPF настроен, а DMARC нет. Без DMARC почтовые системы не знают,
что делать с подделками, и от имени твоего 19-летнего домена можно рассылать
фишинг.

**Где:** Домены → `komandor-nsk.ru` → DNS-записи (управление зоной).

Добавить TXT-запись:

```
Имя:      _dmarc
Тип:      TXT
Значение: v=DMARC1; p=none; rua=mailto:postmaster@komandor-nsk.ru
```

Адрес в `rua` замени на тот, который реально читаешь.

`p=none` — режим наблюдения: ничего не блокируется, но тебе начнут приходить
отчёты, кто шлёт письма от твоего имени. Это правильный первый шаг: сразу
ставить `p=quarantine` рискованно, можно отрезать собственные рассылки.

Через месяц-два, когда по отчётам станет видно, что все легитимные отправители
проходят проверку, ужесточить до `p=quarantine`, затем до `p=reject`.

## 4. khrom-in.ru — решить судьбу домена

Домен пустой: ни сайта, ни почты. При этом на нём висят три услуги. Сначала
реши, нужен ли он, а дальше по одному из двух путей.

### Путь А. Домен нужен

Наполнить зону: A-запись на IP сайта, MX на `nicmail.ru` для почты. Тогда
заработают и почтовый тариф, и сертификат.

Точные значения MX можно взять с рабочего домена — на `komandor-nsk.ru` сейчас:

```
5  mx02.nicmail.ru
10 mx01.nicmail.ru
20 mx03.nicmail.ru
```

И SPF: `v=spf1 redirect=nicmail.ru`. Плюс DMARC как в пункте 3.

### Путь Б. Домен пока не нужен

Тогда стоит явно объявить, что с него не шлют почту — иначе его удобно
использовать для подделок. Две записи:

```
Имя:      @ (сам домен)
Тип:      MX
Значение: .            приоритет 0
```
```
Имя:      @ (сам домен)
Тип:      TXT
Значение: v=spf1 -all
```

Это стандартный способ сказать «домен не отправляет почту». Бесплатный
почтовый тариф на нём тогда можно не продлевать.

## 5. CAA — по желанию

Ни у одного домена нет CAA-записей, то есть сертификат на них может выпустить
любой удостоверяющий центр.

**Осторожно:** CAA — это белый список. Если добавить запись и забыть внести в
неё нужный УЦ, следующий выпуск сертификата сломается. Добавляй, только если
понимаешь, чем будешь выпускать сертификаты. Для текущего GlobalSign через
Руцентр:

```
Имя:      @
Тип:      CAA
Значение: 0 issue "globalsign.com"
```

Если планируешь ещё и Let's Encrypt — нужна вторая запись с
`0 issue "letsencrypt.org"`.

Это гигиена, а не срочность. Пункты 1–3 важнее.

# Часть 2. Что я могу сделать по команде

## Уже умею — данные из кабинета

| Команда | Что делает |
|---|---|
| `python3 tools/nic.py domains` | домены: NS, DNSSEC, флаги переноса |
| `python3 tools/nic.py services` | все услуги: тип, статус, сроки, автопродление |
| `python3 tools/nic.py expiring [дней]` | что истекает в ближайшие N дней (по умолчанию 90) |
| `python3 tools/nic.py dnscheck [домен]` | фактические MX/SPF/DMARC/CAA + список проблем |
| `python3 tools/nic.py token` | перевыпустить токен |
| `python3 tools/nic.py raw GET путь` | произвольный запрос к API |

Скажи «проверь Руцентр» — прогоню всё и покажу, что изменилось с прошлого раза.

## Могу по запросу

- **Следить за сроками.** Поставить регулярную проверку — раз в неделю или
  раз в месяц — и писать тебе, когда что-то подходит к концу или у услуги
  выключено автопродление. Сейчас ближайшее: почта KHR7805387, 23 октября.
- **Проверить DNS после твоих правок.** Внесёшь DMARC — скажи, подтвержу, что
  запись видна снаружи и синтаксис верный.
- **Разобрать DMARC-отчёты.** Когда пойдут `rua`-отчёты, объясню, кто шлёт
  письма от твоего имени и можно ли ужесточать политику.
- **Подготовить зону для khrom-in.ru** — полный список записей под конкретную
  задачу, чтобы ты вставил их в кабинете не думая.
- **Сравнить с альтернативами.** Руцентр в конце 2024 поднял продление `.ru`
  примерно с 1190 до 3129 ₽ и переориентировался на крупный бизнес. Если
  интересно — посчитаю, что выйдет при переносе к другому регистратору и чем
  это грозит.
- **Проверить домен для нового проекта.** Под сайт продажи конструкторских
  услуг — подобрать и проверить свободные имена.

## Чего не могу — и что для этого нужно

- **Менять DNS-записи через API.** Услуги «DNS-хостинг» на договоре нет, зоны
  живут на облачной платформе, её API не отдаёт. Появится услуга — клиент
  заработает как задумано, вместе с черновиками и точным дифом перед
  применением.
- **Включать автопродление и управлять услугами.** Нужны права токена на
  запись в раздел `/services`. Сейчас песочница блокирует даже запрос таких
  прав — разумно, речь о биллинге. Если решишь дать — скажи, и я сначала
  покажу, что именно собираюсь отправить.
- **Заходить в веб-кабинет.** Только API, браузером за тебя не хожу.
- **Проходить идентификацию через Госуслуги.** Только лично.

## Порядок, если делать по-быстрому

1. Идентификация через Госуслуги — до 1 сентября.
2. Автопродление на `komandor-nsk.ru` (почта KOM7674742) и на домен
   `khrom-in.ru`, если он нужен.
3. DMARC на `komandor-nsk.ru`.
4. Решить судьбу `khrom-in.ru`.

Первые три — минут пятнадцать. Четвёртое требует решения, а не действий.

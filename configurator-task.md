## Задача 1. Дополнительные поля при регистрации

**Что сделать:**
Добавить в форму регистрации пользователя два поля дополнительно к ФИО:
- **Ник** (никнейм / отображаемое имя);
- **Должность**.

**Требования:**
- Поля добавляются в форму регистрации и сохраняются в профиле пользователя.
- Отображение этих полей в профиле / карточке пользователя.

**Критерии приёмки:**
- [ ] При регистрации доступны поля «Ник» и «Должность».
- [ ] Значения сохраняются в БД и корректно отображаются в профиле.

**[уточнить]:**
- Обязательные поля или нет?
- Ограничения по длине / допустимым символам для ника?
- Нужна ли уникальность ника?

## Задача 2. Отображение размера детали при выделении

**Что сделать:**
При выделении детали в конфигураторе показывать её размер.

**Требования:**
- При клике / выделении любой детали пользователь видит её размер(ы).
- Размер обновляется при смене выделения на другую деталь.

**Критерии приёмки:**
- [ ] При выделении детали отображается её размер.
- [ ] При снятии выделения / выборе другой детали индикация корректно обновляется.

**[уточнить]:**
- Где показывать размер: всплывающая подсказка у детали, панель свойств сбоку,
  подпись на самой детали?
- Какие размеры показывать: ширина / высота / глубина или только габарит?
- Единицы измерения (мм / см)?

## Задача 3. Индивидуальная глубина полок и внутренних стоек

**Что сделать:**
При выделении полок и внутренних стоек дать возможность задавать им
другой размер по глубине (независимо от общей глубины конструкции).

**Требования:**
- При выделении полки или внутренней стойки доступно поле / элемент управления
  для изменения глубины именно этой детали.
- Изменение глубины применяется только к выбранной детали, не затрагивая остальные.
- Геометрия / визуализация конструкции корректно перестраивается под новую глубину.

**Критерии приёмки:**
- [ ] Для выделенной полки можно задать индивидуальную глубину.
- [ ] Для выделенной внутренней стойки можно задать индивидуальную глубину.
- [ ] Изменение не влияет на глубину других деталей.
- [ ] 3D/2D-модель корректно отображает деталь с новой глубиной.

**[уточнить]:**
- Ограничения на диапазон глубины (мин/макс, кратность)?
- Как обрабатывать зависимость с соседними деталями (стыки, крепления)?
- Влияет ли индивидуальная глубина на расчёт стоимости / спецификацию?
